# Portfolio

My personal portfolio built with [Next.js](https://nextjs.org), TypeScript, and CSS. It showcases my experience, projects, technical interests, and work in software engineering.

## Getting Started

Clone the repository, install dependencies, and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

Built with [Next.js](https://nextjs.org).
